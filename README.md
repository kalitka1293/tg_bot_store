
Интернет магазин Telegram mini app по продаже кондиционеров 

# По данному сайту была защищена дипломная работа, для полного ознакомления с работой смотрите файл ВКР.docx


Это веб-приложение построено с помощью гибридной архитектуры и использует несколько отдельных компонентов:

Главный backend — Django, запущенный в Docker. Он отвечает за все пользовательские интерфейсы, аутентификацию через JWT, обработку товаров, статей, заказов и оплату. В рамках Django приложение разделено на три части: аутентификация и ошибки, визуальное отображение страниц, и функции корзины и заказа.

FastAPI — микросервис для управления корзиной и быстрым поиском товаров с помощью Meilisearch. Он обеспечивает оперативную обработку запросов и поддерживает аутентификацию через токены, выданные Django.

Telegram bot — точка входа для пользователей, позволяющая им аутентифицироваться через Telegram без отдельной регистрации, а также получать уведомления и отправлять данные заказов.

additional service — вспомогательный сервис, который синхронизирует данные товаров с системой поиска Meilisearch через RabbitMQ.

Redis и PostgreSQL обеспечивают хранение и кэширование данных, а Meilisearch отвечает за быстрый поиск товаров.

Для связи между микросервисами используется RabbitMQ, обеспечивающий обмен данными и интеграцию.

Архитектура позволяет легко масштабировать и развивать систему, добавляя новые возможности и улучшая производительность с минимальными изменениями.
